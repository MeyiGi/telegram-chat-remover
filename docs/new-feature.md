# Шаблон новой автоматизации

Перед реализацией заполните короткое описание:

```text
Название:
Запуск: событие Telegram / расписание / проверка внешнего сервиса
Источник: ID сообщений, строки архива, страницы дневника или снимок API
Результат: локальная запись и внешний адрес/страница, если есть
Ключ обработки: значение, по которому повторный запуск узнаёт ту же работу
Настройки: переключатель, адрес назначения, расписание и ключи
Ошибка: когда повторяем и где сохраняем состояние
Исправление: как меняем ошибочно извлечённый или устаревший факт
Приватность: какие данные покидают компьютер
Проверки: обычный случай, ошибка с повтором и дубликат
```

Создайте отдельную папку в `couplebot/features/`. Правила и извлечение данных положите в `service.py`, подписку на события Telegram — в `handlers.py`. Методы хранения или отдельный репозиторий находятся в `couplebot/storage/`, внешний API — в `couplebot/integrations/`. В `couplebot/app.py` подключите сценарий через переданные зависимости. Новые переменные окружения читает только `AppConfig` в `couplebot/config.py`.

Если сценарий запускается сообщением, сначала сохраните сообщение вместе с `(chat_id, message_id)`. После внешней записи сохраните ID созданной страницы или файла. Повторная попытка использует тот же ключ обработки. Для досье и других меняющихся фактов добавляйте версию с источником и временем вместо незаметной замены старого значения.
